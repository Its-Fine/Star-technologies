# Проверка первой версии

Дата: 11 октября 2026 года.

| Проверка | Результат |
|---|---|
| TypeScript, `tsc --noEmit` | Пройдено |
| Производственная сборка Vinext/Workers | Пройдено |
| 8 моделей / 8 категорий / цена `null` / официальные источники | Пройдено |
| Серверный рендеринг 19 публичных страниц, один H1, main, локальные ссылки и изображения | Пройдено |
| 19 групп интеграционных проверок | Пройдено |
| SVG XML и просмотр рендеров иллюстраций | Пройдено |
| Автономная HTML-сборка тех же React-компонентов | Создана |
| Визуальная проверка сайта в браузере, мобильные нажатия и фокус | Не выполнялась: инструмент управления браузером недоступен |
| Lighthouse / скорость на реальном устройстве | Не измерялась |
| Реальная CRM, DNS, домен, рабочая D1/R2 | Не подключались; развёртывание ждёт подтверждения |

Интеграционные проверки используют SQLite в памяти как реализацию SQL API D1 и временное хранилище байтов как реализацию R2. Это проверяет логику, SQL, контракты и ошибки, но не заменяет контрольную отправку после развёртывания в настоящей среде Workers/D1/R2.

Проверены: отключённое хранилище без ложного успеха; origin; поля и согласие; honeypot; запись контактов и валюты; загрузка PDF; идемпотентный повтор; запрет неподдерживаемого расширения и поддельного PDF; предел 10 МБ; авторизация списка и вложений; закрытые ключи хранилища; целостность скачанного файла; настройка курса; отключённая CRM; сохранность заявки при сбое CRM; повтор отправки; ограничение частоты; очистка файла при ошибке записи.

Подход к быстродействию: системный шрифт, локальные векторные изображения, без сторонних виджетов и трекеров, lazy loading ниже первого экрана, ограниченный клиентский код и серверный HTML. Численные показатели Core Web Vitals не заявляются без замера.
