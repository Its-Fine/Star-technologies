# STAR Technologies — первая рабочая версия

Создано 11 октября 2026 года. Сайт **не опубликован**. Публикация — только после подтверждения владельца.

## Посмотреть результат

Откройте `deliverables/STAR_Technologies_preview.html` в браузере. Это автономная сборка из тех же React-компонентов и стилей: работают навигация, поиск, фильтры, карточки, выбор валюты и форма с выбором файла. Отправка из автономного HTML намеренно отключена и явно сообщает об этом; она не показывает ложный успех.

Полная версия включает серверную обработку заявок, базу D1, приватные файлы R2, админку `/admin` и адаптер CRM. После развёртывания и применения миграций форма работает через `/api/leads`.

## Что реализовано

- Главная, каталог, решения, поставки, компания, контакты; четыре страницы решений и восемь карточек моделей, страница данных заявки.
- Восемь категорий: шкафы, PDU, ИБП, аккумуляторы, охлаждение, серверы, СХД, сеть.
- Поиск по модели, артикулу и параметрам, фильтры категории и производителя, пустое состояние с запросом подбора.
- Проверенные характеристики восьми реальных моделей, ссылки на первичные источники. Все цены — `null`, отображение «Цена по запросу». Доступность, партнёрства и выполненные проекты не заявляются.
- Оригинальные векторные изображения категорий. Они явно обозначены иллюстрациями и не выдаются за фотографии конкретных моделей.
- Запрос цены из карточки переносит модель в форму. ТЗ до 10 МБ: PDF, DOC(X), XLS(X), TXT, JPG, PNG.
- Серверная проверка полей, согласия, размеров и начальной сигнатуры файлов; ограничение частоты запросов; защита повторной отправки одним ключом.
- Заявки хранятся в D1; файлы в R2, доступны только через авторизованный API скачивания. При сбое БД загруженный файл удаляется; сбой CRM не теряет принятую заявку.
- `/admin`: просмотр и догрузка заявок, скачивание ТЗ, повтор передачи в CRM, настройка курса USD/RUB.
- Выбор ₽/$ сохраняется как предпочтение браузера и включается в заявку. Курс по умолчанию **не задан**. Валютный расчёт подготовлен для будущих подтверждённых цен.
- Адаптивная верстка, мобильное меню, клавиатурный фокус, семантические заголовки, native dialog, reduced motion, lazy images.
- Отдельные URL, серверный HTML, title/description/canonical, Open Graph, favicon, sitemap.xml, robots.txt. Индексация закрыта до публичного запуска.

## Стек и запуск разработчиком

Node.js 22.13+; React 19 / Vinext; Cloudflare Workers, D1, R2; TypeScript; Drizzle. Lockfile `pnpm-lock.yaml` включён.

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm check
pnpm build
pnpm preview:export
```

Для обычной локальной разработки вне управляемой среды: `pnpm dev`. Это запускает Vinext с локальными привязками D1/R2. В среде Sites используйте штатный Sites workflow и supervisor, не отдельный сервер.

После первой сборки примените каждую **ещё не применённую** локальную миграцию:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_military_alice.sql
```

Миграции локальной и рабочей базы независимы. При публикации через Sites рабочие миграции применяет платформа. `pnpm start` запускает локальную проверку собранного Worker через Wrangler; это не команда публикации.

## Конфигурация

Переменные задаются в защищённых настройках среды исполнения. Не помещайте ключи в frontend, репозиторий или автономный HTML.

| Переменная | Назначение |
|---|---|
| `ADMIN_TOKEN` | Случайный секрет минимум 32 символа для `/admin` и `/api/admin/*`. Без него доступ закрыт. |
| `RATE_LIMIT_SALT` | Случайный секрет для хеширования сетевого идентификатора в ограничителе запросов. |
| `USD_RUB_RATE` | Необязательный исходный курс. Значение, сохранённое через `/admin`, имеет приоритет. |
| `CRM_WEBHOOK_URL` | Необязательный HTTPS endpoint адаптера CRM. Пока отсутствует, заявки сохраняются только на сайте. |
| `CRM_WEBHOOK_TOKEN` | Необязательный Bearer-токен адаптера CRM. |

Курс — управляемая компанией настройка, а не автоматическая котировка. На текущих карточках он не создаёт цены из ничего. Подтверждённые базовые цены можно позднее внести в `lib/catalog.ts` в USD; интерфейс пересчитает их в RUB при наличии курса. При отсутствии курса рублёвая сумма не выдумывается.

## Проверка

Пройден `tsc --noEmit`; создана производственная сборка. `pnpm check` проверяет 19 групп серверного поведения и серверный рендеринг 19 публичных страниц, ссылки, H1 и локальные изображения. Тестовые данные и условные суммы используются только в памяти тестов.

В этой среде нет разрешённого инструмента управления браузером. Реальная браузерная проверка адаптивности, нажатий, фокуса и измерение Lighthouse **не выполнялись**. Не объявлять их пройденными. Перед публикацией открыть автономный файл или подключённую тестовую среду на телефоне и компьютере.
